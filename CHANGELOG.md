# Changelog

## 1.1.0 - 2026-10-05

### Added
- Select text with the mouse: drag, double-click a word, triple-click a line, `Ctrl+A`, `Ctrl+C`, `Esc`, right-click menu (including "Search for ...")
- Windows: PageFlow adds itself to the "Open with" list and to Settings > Default apps the first time the exe runs
- Help menu: "Set as default PDF reader...", "Remove PDF file association entries", "PageFlow on GitHub"
- `--register` and `--unregister` command-line switches
- Credits for the author and the open source libraries in the About dialog, the start screen and the exe's file properties
- Repository files: licence (AGPL-3.0), README with screenshots, credits, tests, GitHub Actions for tests and for building the Windows exe

## 1.0.0 - 2026-10-03

### Added
- First version: continuous-scroll PDF viewer with zoom, rotate, dark pages, search with highlights, thumbnails, outline, password-protected files, drag and drop, recent files, save a copy, copy page text, save page as PNG
- One-click Windows exe build (`build.bat`)
